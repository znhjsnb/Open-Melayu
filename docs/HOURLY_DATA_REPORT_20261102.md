### 1.2 必须区分的两个时间口径

**Git 存档口径**：按里程碑提交时间归属小时，使用该小时结束前最后一个 Git 里程碑快照计算增量。这一口径可通过不可变提交及分片完整复核。

> “本小时 Git 存档净增为零”不等于“本小时没有生产”。
